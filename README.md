# Практика: Реалізація конвеєра команд (Pipeline) в Linux

Цей мініпроєкт демонструє створення власного конвеєра (пайплайна) команд мовою C з використанням системних викликів POSIX. Програма імітує поведінку командної оболонки (shell) при виконанні конструкції з кількома трубами (pipes).

## Завдання (Варіант 11)
Реалізувати програму, яка виконує аналог команди:

cat file.txt | grep word | wc -l
Програма самостійно створює процеси, канали між ними та перенаправляє стандартні потоки вводу/виводу.

##  Використані системні виклики
pipe() — створення анонімних каналів для міжпроцесної взаємодії.

fork() — створення дочірніх процесів для виконання кожної окремої команди.

dup2() — перенаправлення стандартних потоків (STDIN, STDOUT) у канали.

execlp() — заміна образу процесу на виконуваний файл системної утиліти.

waitpid() — очікування завершення роботи дочірніх процесів.

## Архітектура рішення
Програма створює 2 канали (pipes) та 3 дочірні процеси:

Процес 1 (cat): Читає файл file.txt і замість виводу на екран направляє дані на вхід (write-end) Першого каналу.

Процес 2 (grep): Читає дані з виходу (read-end) Першого каналу, фільтрує рядки зі словом "word" і направляє їх на вхід (write-end) Другого каналу.

Процес 3 (wc -l): Читає відфільтровані рядки з виходу (read-end) Другого каналу, рахує їх кількість і виводить результат на стандартний STDOUT (екран).

Важливий нюанс: Батьківський процес та всі дочірні процеси ретельно закривають невикористовувані файлові дескриптори каналів, щоб уникнути зависання (deadlock) при очікуванні EOF (End Of File).
